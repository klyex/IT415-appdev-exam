# Prompt Cycle 05 Submission Documentation

Use this cycle when preparing the AI prompt records, screenshots, and GitHub evidence for submission.

## Goal

Complete the documentation form using actual development evidence from the POS system and the activity PDF requirements.

## Prompt To Use

```text
Help me organize my IT415 AI-assisted development documentation for my assigned POS scenario: [scenario name]. I need at least two AI prompt records used at different development points, each with exact prompt, purpose, AI response summary or screenshot, my evaluation, and modifications I made. I also need a checklist for app screenshots and GitHub commit evidence based on the activity PDF. Use placeholders where I must paste real screenshots, AI responses, or commit messages. Do not invent evidence.
```

## Response Capture

Save the AI response screenshot or summarize the documentation checklist, assigned scenario, and prompt-record structure.

## Evaluation

Mark the response:

- Correct if it follows the PDF/form fields and clearly separates real evidence from placeholders.
- Partially correct if it gives a useful checklist but misses one required screen, prompt field, or commit milestone.
- Incorrect if it fabricates screenshots, commits, AI responses, or student certification details.

## Modifications To Record

Record edits made to match the actual submission, such as adding the assigned scenario, replacing placeholder prompt text with exact prompts used, adding real AI response summaries, matching commit messages to GitHub history, or updating screenshot labels.

## Evidence To Produce

- AI Prompt Record 1 and AI Prompt Record 2.
- Product list or order screen screenshot.
- Cart or order summary screenshot.
- Payment screen screenshot.
- Receipt screen screenshot.
- Commit history screenshot.
- Commit list matching the screenshot.
- Brief README or short project documentation.

## Done Criteria

The form is complete enough for submission, and every evidence field is backed by a real screenshot, summary, commit, or student-provided entry.
